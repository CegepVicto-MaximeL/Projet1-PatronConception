# Patron État : dialogue avec un PNJ (JavaScript)

Le PNJ réagit différemment selon son état : Neutre, Content ou Fâché.

## Exécution (Node.js 14 ou plus, aucune dépendance)

    node main.js

## Fichiers

- `pnj.js` : le contexte
- `etats.js` : les états concrets (Neutre, Content, Fâché)
- `main.js` : le joueur
